# Q-KEF v2 Power Analysis

This is planning analysis, not an experimental result. Under the v1 observed discordance rate (0.0833) and challenger-correct share (0.80), exact-binomial McNemar planning gives:

- Approximate minimum TEST n for 80% power: 277
- Approximate minimum TEST n for 90% power: 359
- Planned confirmatory TEST n: 480
- Estimated power at n=480 under unchanged assumptions: 0.969

The assumptions come from a small prior test and are uncertain. The 2,400-event benchmark remains a future confirmatory target; the current v2 run is explicitly retrospective.
