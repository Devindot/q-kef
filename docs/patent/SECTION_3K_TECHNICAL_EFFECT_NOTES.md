# Technical-Effect Notes

This document does not provide legal advice. Q-KEF v2 attempts to connect mechanisms to measurable computer-system behavior:

- active eligibility plus lifecycle retirement → active index size and search-space reduction;
- witness retrieval on candidate states → obsolete exposure and current-evidence miss before publication;
- graph/index equivalence invariant → consistency rate;
- one-epoch state publication → mixed-epoch exposure count;
- delta plans → embeddings regenerated and index churn per update;
- compact rollback delta → restoration equality and recovery latency;
- deterministic local retrieval → p50/p95 query latency;
- conformal/risk gate → quarantine rate and auto-commit precision;
- failure injection → query availability and unchanged pre-epoch hash.

The retrospective pilot achieved zero mixed-epoch exposure and exact tested rollback, but its high witness current-evidence miss and small synthetic sample constrain interpretation. Local timing is not production-scale evidence.
